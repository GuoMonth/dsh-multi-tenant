# 0.10.0-rc.1

[简体中文](https://github.com/GuoMonth/dsh-multi-tenant/blob/main/docs/zh-CN/release-notes.md)

Released **2026-10-10** to npm `next` and GitHub prerelease. Paired runtime: **0.4.0-rc.1**; DSH: **0.2.0-rc.2**.

- Kubernetes environments with one persistent PVC per user, on DSH 0.2.0-rc.2.
- OIDC membership, native HTTP/WebSocket access, explicit stop/start and revocation.
- Fresh Linux/amd64 installations, one node/platform replica and trusted members. Public interfaces, configuration, CLI and data semantics are frozen for this RC.
