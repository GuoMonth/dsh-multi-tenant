# 0.10.0-rc.1

[简体中文](https://github.com/GuoMonth/dsh-multi-tenant/blob/main/docs/zh-CN/release-notes.md)

- Kubernetes environments with one persistent PVC per user, on DSH 0.2.0-rc.2.
- OIDC membership, native HTTP/WebSocket access, explicit stop/start and revocation.
- English and Chinese guides reorganized; package documentation links identify its source snapshot.
- RC publishes to npm `next` and GitHub prerelease. Scope: fresh Linux/amd64 installations, one node/replica, trusted members. Public interfaces, configuration, CLI and data semantics are frozen.

Paired runtime: 0.4.0-rc.1. Tested scope and artifacts: [Release and validation](https://github.com/GuoMonth/dsh-multi-tenant/releases/tag/v0.10.0-rc.1). Start with [installation](https://github.com/GuoMonth/dsh-multi-tenant/blob/main/docs/en/installation.md). Earlier versions are in [GitHub Releases](https://github.com/GuoMonth/dsh-multi-tenant/releases).
