DSH 0.2.0-rc.2 on Kubernetes, with one persistent environment and PVC per authorized user.

- OIDC login and membership, native DSH HTTP/WebSocket, explicit stop/start and access revocation.
- Fixed Agent Sandbox workload and exact Sandbox/PVC identity checks; normal lifecycle retains files, conversations, configuration and user tool credentials.
- npm includes the Helm installer, Chart and AI installation guide. Start with the [README](https://github.com/GuoMonth/dsh-multi-tenant/blob/v0.10.0-alpha.1/README.md) or [AI guide](https://github.com/GuoMonth/dsh-multi-tenant/blob/v0.10.0-alpha.1/packages/multi-tenant/AI.md).

Install `dsh-multi-tenant@0.10.0-alpha.1`. `release.json` identifies the exact platform/runtime images, sources, bundled Connector and npm integrity; `SHA256SUMS` checks the attached files. The paired runtime release is linked in that manifest.

Alpha: Linux/amd64, one cluster and platform replica, trusted organization members. Requires existing OIDC, DNS/TLS, ingress, CNI and storage. PVC retention is not backup; local-path capacity is not a directory hard quota. No HA or automatic node-partition recovery guarantee. See the attached local validation report for checks and limits.
