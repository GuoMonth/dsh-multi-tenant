# dsh-multi-tenant 0.6.0

Source version 0.6.0 targets exactly DSH `0.1.5-rc.2`, commit `fb2c4b9e698e30edb738bca4cf0618587db7d203`. Release identity is `v0.6.0`, npm dist-tag `latest`; this work prepares source and does not publish or deploy.

- Replaces `withAgent` with explicit send/Queue/Steer, cancel, whenIdle, trusted executeTool and inject. Lifecycle transitions remain serialized; long operations no longer hold up realtime cancellation.
- Adds Principal-authorized cold history and disposable observations over native Session cuts. Human/assistant text is separated from host-injected context; durable cursor catch-up is distinct from transient attempts. Cold reads do not activate Agents or acquire runtime Secrets.
- Derives root-bound child targets from native `subagentCatalog`, verifies their own descriptor/header, and controls continuations through the official host adapter. Native in-process scope inheritance preserves per-Principal MCP credentials and tool restrictions; root teardown drains descendants.
- Resolves own `deliverables/presented` events into authorized current-source file access. Hosts provide an explicit scoped FS capability; GET/HEAD reauthorize, enforce size/type/policy, and abort on disconnect/revocation/deletion. HTML/SVG are inert text.
- Ships an optional loopback Cordis profile and official sidebar/main display plugin. Its bounded adapter panel exercises real DSH native behavior with a keyless model and demo identities; stock privileged controllers are omitted.
- Keeps ready-before-durable publication protection and adds native MCP repeated-cursor failure cleanup. Release gates validate current behavior and packed exports without retired-file or source-text constraints. Packed consumer verification now starts the complete native scoped profile.

The SQLite root ownership schema is unchanged; no compatibility promise is made for old API, schemas or runtimes. Shared execution is logical isolation, not a hostile-code boundary. One active process owns the SQLite directory. Teardown remains cooperative and `whenIdle()` is not a durability barrier.

Full stock Web authority coverage (#71), AgentPresets capability composition (#68), and the pre-existing refresh/disposer edge case (#65) remain explicitly deferred. One-shot children are read-only; deeper cold control requires an active direct parent; remote runs without local Session facts are not addressable Session targets. Native FS backend alias/race guarantees apply, and file access does not create an immutable archive.

Validation: Node 22.19.0/24 release gates, 78 package tests plus release-gate regressions, independent tarball type/API/profile smoke, and three-identity real browser verification with 72 rejected cross-Principal/root requests. See [evidence](../evidence/dsh-rc2/README.md).
