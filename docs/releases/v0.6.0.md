# dsh-multi-tenant 0.6.0

The plugin targets exactly DSH `0.1.5-rc.2` at commit `fb2c4b9e698e30edb738bca4cf0618587db7d203`. Source release identity is `v0.6.0`; distribution uses the `latest` dist-tag. Publication is separate from source preparation.

This baseline retains the per-session durability checkpoint before publishing ready resources. A real MCP repeated-discovery-cursor regression checks provisioning failure and cleanup. Release gates validate the exact dependency graph and installed package contract without preserving retired implementation names or documentation layouts.

Only this exact DSH baseline is supported. Old API, schema and runtime compatibility are not promised. Shared runtime provides logical isolation; authentication, secrets and strong isolation belong to the host. SQLite requires one active process.
