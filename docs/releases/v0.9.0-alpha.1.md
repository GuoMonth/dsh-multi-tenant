# 0.9.0-alpha.1 — Cell platform alpha

Published 2026-09-20: npm channel `latest`; GitHub Release is a regular release marked Latest (`prerelease=false`, `draft=false`). Runtime: [v0.3.0-alpha.1](https://github.com/GuoMonth/dsh-isolated-runtime/releases/tag/v0.3.0-alpha.1), Linux/amd64; exact public Cell/Operator digests are bound in the package cell-release.json.

The CLI now starts the OIDC + Kubernetes Cell platform with `start --config PATH`, and provides private-socket `inspect` and exact-identity `delete`. It no longer starts the old local Docker workbench. Node 24+ and an administrator-configured cluster with direct API/Pod connectivity are required.

The npm tarball includes the platform and pinned internal Connector. Runtime-owned public images are bound by immutable digest, preserving the exact OCI indexes used in regression. Platform and runtime ownership remain separate. See [startup](../reference/quickstart.md) and [release procedure](../reference/release.md).

Breaking configuration/state/API changes are allowed. No historical compatibility, upgrade, HA or seamless recovery promise. Core evidence: [2026-09-20 regression](../evidence/cell-regression-2026-09-20.md). The [delivery verification](../evidence/alpha-delivery-2026-09-20.md) is a historical pre-publication snapshot; the subsequent public npm/release outcome is recorded in [Issue #82](https://github.com/GuoMonth/dsh-multi-tenant/issues/82).
