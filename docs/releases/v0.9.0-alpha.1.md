# 0.9.0-alpha.1 — Cell platform candidate

Not published yet. Intended npm channel: latest; GitHub release: prerelease.

The CLI now starts the OIDC + Kubernetes Cell platform with `start --config PATH`, and provides private-socket `inspect` and exact-identity `delete`. It no longer starts the old local Docker workbench. Node 24+ and an administrator-configured cluster with direct API/Pod connectivity are required.

The npm tarball includes the platform and pinned internal Connector. Runtime-owned public images must be bound before publication; the source manifest deliberately has no invented digests. Platform and runtime ownership remain separate. See [startup](../reference/quickstart.md) and [release procedure](../reference/release.md).

Breaking configuration/state/API changes are allowed. No historical compatibility, upgrade, HA or seamless recovery promise. Core evidence: [2026-09-20 regression](../evidence/cell-regression-2026-09-20.md). Packaging evidence and remaining release work: [delivery verification](../evidence/alpha-delivery-2026-09-20.md).
