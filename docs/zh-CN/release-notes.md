# 0.10.0-rc.1

[English](https://github.com/GuoMonth/dsh-multi-tenant/blob/main/docs/en/release-notes.md)

**2026-10-10 已发布**，使用 npm `next` 和 GitHub 预发布。配套 runtime **0.4.0-rc.1**，DSH **0.2.0-rc.2**。

- Kubernetes 用户环境，每用户一个持久 PVC，使用 DSH 0.2.0-rc.2。
- OIDC 成员管理、原生 HTTP/WebSocket 访问、显式启停与撤权。
- 支持 Linux/amd64、单节点、平台单副本、可信成员和全新安装。本 RC 冻结公开接口、配置、CLI 和数据语义。

使用从[安装](https://github.com/GuoMonth/dsh-multi-tenant/blob/main/docs/zh-CN/installation.md)开始。精确制品与实测范围见[发行版本](https://github.com/GuoMonth/dsh-multi-tenant/releases/tag/v0.10.0-rc.1)和[验证报告](https://github.com/GuoMonth/dsh-multi-tenant/releases/download/v0.10.0-rc.1/validation.md)。更早版本保留在 [Releases](https://github.com/GuoMonth/dsh-multi-tenant/releases)。
